# Assumption Audits

Surfaces, stress-tests, and monitors the assumptions underneath a strategy, model, plan, or recommendation. Use this before any major recommendation is finalised, or when a red-team review or pre-mortem is needed.

```
Skill("consulting-os-assumption-audits", args="$ARGUMENTS")
```

## Examples

```
/consulting-os:assumption-audits red-team the assumptions behind this business case
/consulting-os:assumption-audits pre-mortem this strategy before it goes to the board
```
