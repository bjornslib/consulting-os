# Executive Narrative

Turns analysis into a persuasive executive narrative and deck: a pyramid-principle storyline, action titles, and evidence-backed pages. Produces the storyline and page architecture; pair with a pptx or docx skill for file production.

```
Skill("consulting-os-executive-narrative", args="$ARGUMENTS")
```

## Examples

```
/consulting-os:executive-narrative turn this analysis into a steerco storyline
/consulting-os:executive-narrative draft the action titles for this deck
```
