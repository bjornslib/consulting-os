# Plan an Engagement

Selects and sequences the right subset of the 21 consulting-os skills for an engagement, runs engagement hygiene (single-sourced artefacts, the assumption-audit gate, continuous stakeholder alignment), and turns a finished engagement into reusable IP.

```
Skill("consulting-os", args="$ARGUMENTS")
```

## Examples

```
/consulting-os:plan a pricing engagement for a mid-market SaaS client
/consulting-os:plan harvest this finished engagement into reusable frameworks
```
