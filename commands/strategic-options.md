# Strategic Options

Generates genuinely distinct strategic options and scores them against explicit criteria to reach a recommendation. Use this once analysis is done and a choice must be structured, not just discussed.

```
Skill("consulting-os-strategic-options", args="$ARGUMENTS")
```

## Examples

```
/consulting-os:strategic-options generate distinct options for our market entry decision
/consulting-os:strategic-options what should the client do about declining margins
```
