# Portfolio Review

Reviews a portfolio of business units, products, initiatives, or clients to decide where to invest, hold, fix, or exit. Use this for portfolio reviews, product rationalisation, or resource allocation across units.

```
Skill("consulting-os-portfolio-review", args="$ARGUMENTS")
```

## Examples

```
/consulting-os:portfolio-review review our product portfolio for invest/hold/exit calls
/consulting-os:portfolio-review should we divest this business unit
```
