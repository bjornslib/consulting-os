# KPI Architecture

Designs the measurement system for a strategy or transformation: a driver-linked KPI tree, leading and lagging indicators, targets, owners, and dashboards. Use this for performance management design or target-setting.

```
Skill("consulting-os-kpi-architecture", args="$ARGUMENTS")
```

## Examples

```
/consulting-os:kpi-architecture design the KPI tree for this transformation
/consulting-os:kpi-architecture how do we know if this strategy is working
```
