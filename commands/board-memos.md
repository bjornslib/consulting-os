# Board Memos

Writes decision-grade board memos and papers: a clear ask, the case for and against, the risks, and a specific decision to record. Use this whenever a written document must carry a decision without its author in the room.

```
Skill("consulting-os-board-memos", args="$ARGUMENTS")
```

## Examples

```
/consulting-os:board-memos write the board paper for this investment decision
/consulting-os:board-memos draft a decision memo for the investment committee
```
