# Profit Pool Analysis

Maps where profit actually sits across a value chain, industry, or customer base, and where it is shifting. Use this when strategy work needs to know which activities, segments, or players capture the profit rather than just the revenue.

```
Skill("consulting-os-profit-pool-analysis", args="$ARGUMENTS")
```

## Examples

```
/consulting-os:profit-pool-analysis where is the money actually made in this value chain
/consulting-os:profit-pool-analysis map margin capture across our industry
```
