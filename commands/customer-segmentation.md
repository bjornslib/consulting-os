# Customer Segmentation

Segments a customer base or market into groups that behave differently and can be served and reached differently. Use this whenever strategy, pricing, or go-to-market work needs to know which customers matter and why.

```
Skill("consulting-os-customer-segmentation", args="$ARGUMENTS")
```

## Examples

```
/consulting-os:customer-segmentation segment our customer base by needs, not demographics
/consulting-os:customer-segmentation define the ICP for our new product
```
