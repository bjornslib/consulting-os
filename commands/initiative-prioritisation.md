# Initiative Prioritisation

Prioritises a set of initiatives, projects, or use cases against value, feasibility, and capacity, producing a sequenced, funded list and an explicit not-doing list. Use this whenever the organisation cannot do everything at once.

```
Skill("consulting-os-initiative-prioritisation", args="$ARGUMENTS")
```

## Examples

```
/consulting-os:initiative-prioritisation prioritise our AI use-case backlog
/consulting-os:initiative-prioritisation rank these 20 initiatives against our capacity
```
