# Problem Framing

Frames a client problem precisely and decomposes it into a MECE issue tree before any analysis begins. Use this at the start of an engagement, workshop, or proposal, or whenever a vague brief needs structuring into hypotheses.

```
Skill("consulting-os-problem-framing", args="$ARGUMENTS")
```

## Examples

```
/consulting-os:problem-framing our client wants to grow revenue 20% but doesn't know how
/consulting-os:problem-framing structure this brief into an issue tree
```
