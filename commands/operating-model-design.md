# Operating Model Design

Designs or redesigns how an organisation delivers its strategy: structure, process, governance, capability, technology, and ways of working. Use this whenever a strategy needs to change how the organisation runs, including AI adoption.

```
Skill("consulting-os-operating-model-design", args="$ARGUMENTS")
```

## Examples

```
/consulting-os:operating-model-design design the target operating model for this merger
/consulting-os:operating-model-design should this function centralise or decentralise
```
