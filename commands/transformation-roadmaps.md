# Transformation Roadmaps

Turns prioritised initiatives into an executable transformation roadmap: waves, milestones, dependencies, owners, funding gates, and change management. Use this when a plan needs to show how delivery actually happens.

```
Skill("consulting-os-transformation-roadmaps", args="$ARGUMENTS")
```

## Examples

```
/consulting-os:transformation-roadmaps build the delivery roadmap for this transformation
/consulting-os:transformation-roadmaps sequence these initiatives into waves
```
