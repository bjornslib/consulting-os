# Business Cases

Builds a decision-grade business case or financial model: drivers, scenarios, NPV/payback, and the honest risks. Use this whenever the economics behind a recommendation need to be quantified for a decision-maker.

```
Skill("consulting-os-business-cases", args="$ARGUMENTS")
```

## Examples

```
/consulting-os:business-cases build the business case for this investment
/consulting-os:business-cases is this expansion worth funding
```
