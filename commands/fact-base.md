# Fact Base

Builds the shared, sourced fact base for an engagement: the numbers and facts everyone argues from. Use this to gather, verify, and organise evidence before claims go into a deliverable.

```
Skill("consulting-os-fact-base", args="$ARGUMENTS")
```

## Examples

```
/consulting-os:fact-base build the data book for this market entry engagement
/consulting-os:fact-base verify the revenue figures we've been quoting
```
