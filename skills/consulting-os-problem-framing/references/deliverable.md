# Problem Framing — Output Template & Quality Bar

## Output template

```
## Problem statement (SCQA)
Situation / Complication / Governing question / Working hypothesis

## Issue tree
[Governing question]
├── Issue 1 (logic: …)
│   ├── Sub-issue 1.1 → analysis, data source, priority
│   └── Sub-issue 1.2 → …
├── Issue 2 …
└── Issue 3 …

## MECE check
Overlaps found and resolved: … / Gaps found and closed: …

## Day-one workplan
Prioritised leaves with analysis, data, owner, sequence.
```

## Quality bar

- The governing question is a decision, not a theme. "Growth" is not a question.
- Every branch is phrased so evidence could refute it.
- The tree's logic is named; a reader can verify MECE without guessing.
- No branch survives that would not change the answer if resolved.
