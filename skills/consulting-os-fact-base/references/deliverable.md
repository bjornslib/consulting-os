# Fact Base — Output Template & Quality Bar

## Output template

```
## Headline facts (client sign-off page)
5–10 facts that frame the engagement, each with source and grade.

## Fact ledger
| # | Fact | Value | Period | Source | Grade | Serves branch | Notes |

## Conflicts and resolutions
Where sources disagreed, what was chosen and why.

## Gaps
Facts still needed, proposed source, blocker.
```

## Quality bar

- No unsourced numbers. "Industry sources suggest" is not a source.
- Grades are honest — an analyst estimate is C, not B, no matter how confident it sounds.
- The sponsor could hand this ledger to their CFO without embarrassment.
- Gaps are visible, not hidden. A known gap is workable; a hidden one is a landmine.
