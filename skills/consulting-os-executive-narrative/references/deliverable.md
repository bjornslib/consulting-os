# Executive Narrative — Output Template & Quality Bar

## Output template

```
## Governing thought
One assertive sentence.

## Pyramid
Governing thought → key lines (MECE, ordered with stated logic) → supporting points.

## Ghost deck
Numbered action titles in sequence, readable as a standalone argument.

## Page specs
Per page: title / exhibit or argument / source / appendix-or-body verdict.

## Executive summary page
SCQ in two lines + answer + key lines.
```

## Quality bar

- Every title is a full-sentence assertion; zero label titles.
- Titles read in sequence as a complete, ordered argument.
- One claim, one proof per page; sources on every exhibit.
- The likely attack page has been identified and reinforced.
