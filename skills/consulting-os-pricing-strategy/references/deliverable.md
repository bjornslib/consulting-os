# Pricing Strategy — Output Template & Quality Bar

## Output template

```
## Value baseline by segment
Value created / next-best alternative / WTP evidence.

## Price metric decision
Options considered, risk-shift trade-offs, choice and rationale.

## Architecture
Tiers × segments, fencing logic, upgrade path.

## Levels and evidence
Candidate levels, modelled volume–margin trade-off, test plan if needed.

## Discount governance
Waterfall, authority matrix, what discounts must buy.

## Migration plan
How existing customers move, grandfathering, communication risks.
```

## Quality bar

- Metric and architecture were decided before the number.
- Levels rest on evidence or a defined test, not "10% feels right".
- The realised-price waterfall is confronted, not just list price.
- Existing-customer migration is planned, since that is where pricing changes actually die.
