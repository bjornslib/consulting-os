# Transformation Roadmaps — Output Template & Quality Bar

## Output template

```
## Destination and proof points
Target state; 3–5 observable proofs.

## Wave plan
| Wave | Theme | Key milestones (definition of done) | Exit criterion | Owner | Funding |

## Dependency map
Critical path, hard vs soft dependencies, longest-lead item and its start date.

## Change plan per wave
Affected groups, gains/losses, comms and training, absorption check.

## Steering
Cadence, leading indicators, escalation thresholds, re-planning trigger.
```

## Quality bar

- Wave exits are result-gated, not date-gated.
- Every milestone has a single named owner and a verifiable definition of done.
- The change-absorption check was actually run against the affected teams' other commitments.
- A re-planning mechanism exists — the roadmap admits it will need revision.
