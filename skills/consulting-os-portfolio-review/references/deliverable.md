# Portfolio Review — Output Template & Quality Bar

## Output template

```
## Units and clean economics
| Unit | Revenue | Margin (fully loaded) | Growth | Capital employed |

## Grid placement
Attractiveness / position / ownership-fit verdict per unit, with rationale.

## Postures
Invest / hold / fix (condition + date) / exit (path + value) per unit.

## Portfolio system test
Cash balance, concentration risks, coherence.

## Allocation
Capital and talent shifts, summing to available resources.
```

## Quality bar

- Shared-cost allocation logic is stated; no unit hides in "corporate".
- The ownership-fit question is asked of good businesses too.
- "Fix" verdicts carry dates and conditions — indefinite fixing is holding in denial.
- The allocation table sums; postures without resource shifts are commentary.
