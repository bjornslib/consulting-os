# Customer Segmentation — Output Template & Quality Bar

## Output template

```
## Segmentation basis and rationale
Which basis, serving which decision.

## Segment cards (one per segment)
Name / defining need or behaviour / identification markers / size and economics / current share of client's revenue / what winning them requires.

## Value concentration
Where revenue and margin actually sit across segments.

## Target priority
Ranked segments with the reason and the implied action.
```

## Quality bar

- Passes distinct/identifiable/substantial/actionable — stated explicitly, not assumed.
- Identification markers exist in data the client actually holds or can obtain.
- At least one segment is explicitly *de-prioritised* — a segmentation that targets everyone decides nothing.
