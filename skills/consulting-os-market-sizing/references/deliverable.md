# Market Sizing — Output Template & Quality Bar

## Output template

```
## Market definition
Boundaries (product / customer / geography / period / unit).

## Sizing
Top-down: anchor → filters → result (each filter sourced).
Bottom-up: units × penetration × price → result.
Triangulation: convergence or reconciliation of the gap.

## TAM / SAM / SOM
Each layer with the constraint logic applied.

## Growth outlook
Driver decomposition, 3–5 year view, key sensitivities.

## Confidence statement
Range, weakest input, what data would tighten it.
```

## Quality bar

- Every percentage in the funnel has a source or explicit reasoning — no naked assumptions.
- Bottom-up and top-down are genuinely independent (no shared inputs).
- SOM has a capture logic tied to sales capacity and competitive response.
- The confidence statement names the weakest link honestly.
