# Strategic Options — Output Template & Quality Bar

## Output template

```
## Governing question and criteria
Question; weighted evaluation criteria (agreed before scoring).

## Option cards (3–5)
Thesis / requires / forecloses / first 90 days / kill condition.

## Evaluation matrix
Options × criteria, scored with rationale per cell.

## Recommendation
Chosen option; why it beat the runner-up; staging; kill condition restated.
```

## Quality bar

- Every option could be genuinely championed; the status quo is honestly rendered.
- Criteria and weights were fixed before scoring.
- The recommendation names the runner-up and the deciding factor.
- Kill conditions are observable and dated.
