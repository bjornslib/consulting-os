# Strategic Options

Most "options papers" contain one real option, one straw man, and the status quo. This skill forces genuinely distinct, coherent options, evaluates them honestly, and recommends one — with the losing options treated seriously enough that the choice means something.

## Method

**1. Anchor on the governing question and the fact base.** Options answer the framed question; they are not free-floating ideas.

**2. Generate 3–5 genuinely distinct options.** Use where-to-play × how-to-win as the generator: each option is a coherent combination of target segments, offer, channel, and economic engine. Tests of distinctness:
- The options would lead to visibly different companies in three years.
- Each option, if chosen, forecloses something another keeps open.
- A reasonable executive could champion each one — no straw men.
Include the honest status quo ("continue and optimise") as a real option with its real trajectory, not a caricature.

**3. Make each option concrete.** For each: the thesis in one sentence; what it requires (capital, capability, time); what it forecloses; the first 90 days; and its kill condition — the observable result that would prove it wrong.

**4. Evaluate against explicit, weighted criteria.** Typical set: value creation potential, fit with capabilities, risk, reversibility, speed to impact, funding requirement. Agree criteria and weights *before* scoring — criteria chosen after scoring are rationalisation. Score with rationale per cell, not bare numbers.

**5. Stress the leader.** Run the leading option through assumption audit and, where competitive response matters, war-gaming. An option that only wins if competitors sleep is not the leader.

**6. Recommend and stage.** State the recommendation, why it beat the runner-up specifically, and whether commitment can be staged (options-based staging beats all-in where uncertainty is high).

Before drafting the final deliverable, load `references/deliverable.md` for the output template and quality bar.
