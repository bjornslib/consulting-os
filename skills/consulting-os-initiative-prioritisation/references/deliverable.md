# Initiative Prioritisation — Output Template & Quality Bar

## Output template

```
## Initiative cards (normalised)
| Initiative | Outcome | Value ($ + strategic) | Cost | Duration | Feasibility factors | Confidence |

## Scoring matrix
Value × feasibility with per-cell rationale; capacity cut line shown.

## Sequenced plan
Waves with dependency and learning-value logic.

## Not-doing list
Killed/parked items, reason, revival condition.
```

## Quality bar

- Estimates were normalised before comparison.
- Strategic value is visible and separate, not smuggled into a blended score.
- The cut line reflects actual capacity, including change absorption.
- The not-doing list exists and has been socialised with the owners of the killed items.
