# Operating Model Design — Output Template & Quality Bar

## Output template

```
## Design criteria
Must-win capabilities / deliberate non-goals / constraints.

## Target model by layer
Value streams → capabilities (incl. human–machine split) → structure (grouping logic + named tax) → decision rights table → technology/data assumptions → people and incentives.

## Scenario walk-throughs
3–5 scenarios; where the model succeeded or was fixed.

## Transition
Gap per layer, sequence with rationale, cost/disruption estimate.
```

## Quality bar

- Structure came last, derived from streams and capabilities.
- Every grouping choice names what it taxes and how that is mitigated.
- The decision-rights table covers the contentious decisions, not the easy ones.
- The design survived concrete scenario walk-throughs on paper.
